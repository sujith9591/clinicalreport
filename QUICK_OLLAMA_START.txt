STEP 1: DOWNLOAD OLLAMA (5 minutes)
─────────────────────────────────────────────────────────────────────

1. Go to: https://ollama.ai
2. Click "Download"
3. Click "Download for Windows"
4. Save OllamaSetup.exe

═══════════════════════════════════════════════════════════════════════

STEP 2: INSTALL OLLAMA (5 minutes)
─────────────────────────────────────────────────────────────────────

1. Double-click OllamaSetup.exe
2. Click "Next" on all prompts
3. Click "Install"
4. Click "Finish"
5. RESTART YOUR COMPUTER (required!)
6. Verify: Open PowerShell, run: ollama --version

═══════════════════════════════════════════════════════════════════════

STEP 3: DOWNLOAD MODEL (15 minutes)
─────────────────────────────────────────────────────────────────────

Open PowerShell and run:

    ollama pull llama3.2

Wait for ~6-7GB download to complete. You'll see:
    pulling manifest
    downloading 123456... [===============>      ] 85%
    (wait for 100%)

═══════════════════════════════════════════════════════════════════════

STEP 4: UPDATE CONFIGURATION (2 minutes)
─────────────────────────────────────────────────────────────────────

Edit file: config.yaml

FIND THIS:
    llm:
      base_url: http://3.94.255.185:11434

CHANGE TO:
    llm:
      base_url: http://localhost:11434
      timeout_seconds: 60

SAVE FILE!

═══════════════════════════════════════════════════════════════════════

STEP 5: START OLLAMA SERVER (ongoing)
─────────────────────────────────────────────────────────────────────

Open PowerShell and run:

    ollama serve

You should see:
    Listening on 127.0.0.1:11434

KEEP THIS WINDOW OPEN! (This is your server running)

TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────

Problem: Timeout after 30 seconds
Solution: Increase timeout_seconds to 60 in config.yaml

Problem: "Connection refused"
Solution: Make sure ollama serve is running in another PowerShell

Problem: "Model not found"
Solution: Run: ollama pull llama3.2

Problem: Tests fail
Solution: Check ollama serve window is still open and running
